# Project Templates and Examples

This directory contains sample projects and templates for the Unity 2D Automation course.

## Structure

### Sample Projects
- `week-01-basics/` - Basic Unity 2D setup and sprite handling
- `week-02-physics/` - Physics and animation examples
- `week-03-scripting/` - C# scripting fundamentals
- `week-04-patterns/` - Design patterns implementation
- `week-05-ui/` - User interface examples
- `week-06-audio/` - Audio integration samples
- `week-07-automation/` - Basic automation scripts
- `week-08-testing/` - Unit testing examples
- `week-09-cicd/` - CI/CD pipeline templates
- `week-10-performance/` - Performance optimization examples
- `final-project-template/` - Complete game project template

### Project Templates
Each project template includes:
- Unity project files
- Configured build settings
- Basic automation scripts
- README with setup instructions
- Example assets and scenes

## How to Use

1. Copy the template folder to your workspace
2. Open with Unity Hub
3. Follow the README instructions in each project
4. Modify and experiment with the provided examples
