# Auto2D Unity - Course Materials

Welcome to the **Unity 2D Game Development with Automation** course! This repository contains all the materials, examples, and resources needed for learning Unity 2D development with a focus on automation techniques.

## 🎯 Course Overview

This comprehensive 12-week course teaches Unity 2D game development while emphasizing automation tools, testing, and best practices that are essential in modern game development workflows.

**Key Features:**
- Complete Unity 2D development curriculum
- Automation-focused approach
- Hands-on projects and exercises
- Industry-standard practices
- CI/CD pipeline integration

## 📚 Course Structure

The course is divided into 6 main modules over 12 weeks:

1. **Module 1:** Unity 2D Fundamentals (Weeks 1-2)
2. **Module 2:** Game Mechanics and Scripting (Weeks 3-4)
3. **Module 3:** User Interface and Audio (Weeks 5-6)
4. **Module 4:** Automation Fundamentals (Weeks 7-8)
5. **Module 5:** Advanced Automation and Performance (Weeks 9-10)
6. **Module 6:** Final Project and Deployment (Weeks 11-12)

📖 **[View Complete Course Outline](./COURSE_OUTLINE.md)**

## 🚀 Quick Start

### Prerequisites
- Basic programming knowledge (C# preferred)
- Unity 2022.3 LTS or later
- Git for version control
- Text editor (VS Code recommended)

### Getting Started
1. Clone this repository
2. Install Unity Hub and Unity 2022.3 LTS
3. Review the [Course Outline](./COURSE_OUTLINE.md)
4. Set up your development environment
5. Join the course discussion forum
